# 벤치마킹: 정부지원금·생활혜택 정보 SNS 채널

- 작성/확인일: 2026-11-06
- 방법: 공개 웹 정보만 사용(WebSearch, WebFetch). 로그인 없이 열리는 프로필·게시물, 검색엔진 색인 스니펫, 운영사 홈페이지.
- 표기 원칙
  - **미확인**: 로그인 화면만 나오거나, 수치·이미지를 볼 수 없었던 항목. 추정치를 사실처럼 쓰지 않음.
  - **[직접 확인]**: 2026-11-06에 WebFetch로 공개 페이지에서 직접 본 값.
  - **[검색 색인]**: 검색엔진이 저장해 둔 프로필 스니펫 값. 수집 날짜가 표시되지 않으므로 현재 값과 다를 수 있음.
  - **[자사 주장]**: 운영사가 스스로 밝힌 값. 측정 기준·날짜가 공개되지 않았고 독립 검증도 안 됨.
- 접근 제약(이번 조사에서 실제로 겪은 것)
  - Instagram: WebFetch가 HTTP 429(요청 과다)를 반환함. 프로필·게시물 이미지를 볼 수 없어 **디자인 항목은 대부분 미확인**.
  - Facebook: 로그인 화면만 나옴. 수치는 검색 색인 값만 있음.
  - X: WebFetch가 HTTP 402를 반환함. 프로필 팔로워 수는 모두 **미확인**.
  - Threads: 일부 프로필은 로그인 없이 열림(최근 게시물 일부와 팔로워 수 확인 가능). 일부(@good_sangga, @moneygraphy)는 로그인 화면만 나왔고, 연속 요청 시 429가 발생함.
  - govinfoma.com(X 계정 @govinfom의 연결 사이트), infong.kr(인퐁 홈페이지): 이 세션에서 접속 불가(DNS 실패, 503). 내용 **미확인**.

## 6. 이번 제작에 적용할 요소 (구성·전달 원리만, 복제 금지)

1. **프로필 = 구독 약속 3줄**: 소개글에 "무엇을 / 얼마나 자주 / 누구에게"를 목록형으로 고정한다(분양통·인퐁의 카테고리 고정 원리). 문구는 우리 것으로 새로 쓴다.
2. **첫 줄은 결론, 둘째 줄부터 근거**: "누가 / 얼마 / 언제까지"를 첫 줄에 넣고, 이어서 ✅ 체크리스트(대상·금액·기간·신청처)로 본문 안에서 완결한다. 링크만 주는 "본문+링크 댓글" 쌍 구조는 쓰지 않는다(연결형 계정은 팔로워가 쌓이지 않았음).
3. **대상자 지정 + 마감·시행일 명시**: 공공 계정처럼 "○○ 가구라면", "신청 ~11/30" 식으로 대상과 날짜를 분명히 적는다. 지난 일정 재게시, "100만원 날림" 같은 과장 표현, 확인 안 된 "실제 후기"는 쓰지 않는다(소형 계정들에서 관찰된 신뢰 저하 요인).
4. **연결은 본문이 아니라 프로필/고정 게시물에서**: 블로그·채널 링크는 프로필과 고정 게시물("이번 달 바뀐 기준 총정리")에 두고, 개별 게시물은 출처(복지로·정부24·해당 기관 공고)를 표기한다. 팔로워를 장기적으로 담을 자체 채널(예: 카카오 채널/뉴스레터)을 두는 구조는 분양통에서 참고.
5. **주기 고정 + 저장 유도**: "매일/매주 ○요일" 같은 업데이트 주기를 정하고, 체크리스트형 게시물은 "저장해두고 신청 전에 확인" 용도로 설계한다(인퐁 "매일 업데이트", 소형 계정의 "저장해둬" 유도 원리).

# 디피로그 글 레이아웃 규격 v1 (매 글 반복 적용)

기준: korea-rich.kr「퇴직연금 디폴트옵션 변경 방법 2026 총정리」구조 (2026-11-06 분석)
적용: 버튼은 **디피로그 detail-button**, 광고는 **디피로그 애드센스**, 색은 디피로그 청록 계열.
원본 템플릿: `post_template.html` ({{}}만 교체)

## 1. 글 순서 (고정)
1. **한눈에 보기 박스**(그라데이션) — 핵심 요약 3~4줄(굵게, 흰 글씨). 핵심 답(날짜·금액·대상)은 여기서 바로.
   - 목차는 넣지 않는다: 디피로그 목차 플러그인(Easy TOC)이 첫 H2 앞에 자동 삽입함(2026-11-06 확인, 중복 방지).
   - 디피로그 테마가 H2에 분홍 그라데이션 바 스타일을 자동 적용하고, 자동 광고(자세히 알아보기 링크 광고 등)도 추가로 삽입됨.
2. **광고1** (라벨 없이 ins만)
3. **버튼1** — 공식 사이트
4. H2 ① 10초 요약/단계 📝 — 1·2·3단계 흰 카드
5. H2 ② 비교표 💡 — 표 1개 + 해석
6. H2 ③ 항목 카드 🏦 → **버튼2** → **광고2** → **본문 이미지**(figure+캡션)
7. H2 ④ 경우별 절차 💰 — 카드
8. H2 ⑤ 주의점 💡 — 왼쪽 선 박스
9. H2 ⑥ 자주 묻는 질문 FAQ 📝 — 질문마다 왼쪽 선 박스 (3개 이상)
10. H2 ⑦ 마무리 — 핵심 3가지(첫째·둘째·셋째) + 행동 권유 → **버튼3** → **광고3**

→ 광고 3개 / 버튼 3개 / 표 1개 / 본문 이미지 1장 / H2 7개

## 2. 글자 스타일
| 요소 | 규격 |
|---|---|
| 제목(H1) | "주제 2026 총정리 (핵심 키워드·절차)" 또는 디피로그 기존 패턴 "주제 2026｜키워드·키워드 5가지" |
| 소제목 H2 | 26px · **굵기 700** · 줄간격 1.35 · 색 #0B3A53 · 끝에 이모지 1개(📝💡🏦💰) · 위 44px/아래 18px 여백 |
| 본문 p | 17px · 굵기 400 · 줄간격 1.8 · 문단 2~3문장 · **문장 끝 마침표마다 빈 줄(<br><br>)** (사용자 지시 2026-11-06) |

| 카드 | 흰 배경 · 1px #e5e7eb 테두리 · 둥글기 20px · 옅은 그림자 · "**항목** · 설명" 형식 |
| 주의/FAQ 박스 | #f1f5f9 배경 · 왼쪽 5px 청록(#1A9BB8) 선 |

## 3. 버튼 (디피로그 전용)
```html
<p><a class="detail-button" href="URL" target="_blank" rel="noopener">👉 무엇을 확인하는지 구체적으로 →</a></p>
```
- 반드시 `<div id="onepage-eitc" class="rf-article-v2">` 안에 있어야 디피로그 버튼 디자인(검정 버튼·빛 효과)이 적용됨.
- 문구는 "자세히 보기" 금지 → "국세청 홈택스 장려금 신청 화면 바로가기"처럼 목적지를 구체적으로.

- **'광고' 라벨·테두리 카드 넣지 않음** (사용자 지시 2026-11-06). 디피로그 기존 글과 같은 맨 ins 태그만.
- 위치: 요약 아래 / 3번째 H2 버튼 뒤 / 마무리 버튼 뒤 (3개).
- 광고와 버튼은 붙어 있으므로 버튼 문구를 광고처럼 보이지 않게(공식 기관명 명시). 애드센스 정책상 광고를 "클릭하라"는 유도 문구 금지.
- 디피로그 테마가 자동 광고도 넣고 있으면 총 개수가 과도해지지 않는지 발행 후 화면에서 확인.

## 5. 이미지
| 종류 | 크기 | 구도 |
|---|---|---|
| 썸네일(대표 이미지) | 1536×1024 (3:2) | 어두운 배경, **왼쪽**에 큰 제목 2줄(흰색 900) + 노란 배지 1개(핵심 조건) + 작은 보조 문구 1줄 / **오른쪽**에 주제 사물 사진·일러스트 |

## 6. 발행 체크
- 대표 이미지 설정 / 카테고리(생활·교통정보, 정부지원금·청년정책, 부동산·청약/대출정보) / 태그 5~8개
- 버튼 링크 3개 클릭 확인, 표 모바일 가로 넘침 확인, 광고 3칸 표시 확인

## 7. Rank Math 85점 이상 (사용자 지시 2026-11-06, 첫 글 86점 달성)
- 포커스 키워드 1개 정하기(예: '근로장려금 기한 후 신청') → 원고 상단 주석에 기록
- 제목 맨 앞에 키워드 + 숫자(2026, 5가지 등)
- 슬러그 = 키워드를 하이픈으로(예: 근로장려금-기한-후-신청)
- 한눈에 보기 요약 첫 문장을 키워드로 시작(콘텐츠 처음 10%)
- H2 2~3개에 키워드 포함, 이미지 alt에 키워드
- 키워드 밀도 1~1.5%(본문 800단어면 8~12회), 본문 800단어 이상
- 메타 설명에 키워드(Rank Math updateMeta: rank_math_focus_keyword, rank_math_description)
- 외부 공식 링크 1개 이상 + 디피로그 내부 링크 1개 이상
- 발행 후 편집 화면에서 점수 확인 → 85 미만이면 위 항목 보완
